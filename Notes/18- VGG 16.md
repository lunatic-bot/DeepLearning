After AlexNet, researchers asked:

> "Do we really need large filters like 11×11 and 5×5? What happens if we make the network deeper?"

This led to **VGGNet**.

---

# VGGNet (2014)

Paper:

Very Deep Convolutional Networks for Large-Scale Image Recognition

Developed by:

Visual Geometry Group (hence the name "VGG").

---

# Main Idea

AlexNet used:

```text
11×11 → 5×5 → 3×3
```

VGG proposed:

> Use only small 3×3 filters everywhere and make the network deeper.

---

# Why Small Filters?

Suppose you want a receptive field similar to a 7×7 convolution.

Option 1:

```text
One 7×7 Conv
```

Parameters:

```text
7 × 7 = 49 weights/filter
```

Option 2:

```text
3×3
 ↓
3×3
 ↓
3×3
```

Effective receptive field ≈ 7×7.

Parameters:

```text
9 + 9 + 9 = 27
```

Much fewer parameters.

---

# Another Benefit

Each convolution is followed by ReLU.

So:

```text
3×3 → ReLU → 3×3 → ReLU → 3×3
```

adds more non-linearity.

This helps learn more complex features.

---

# VGG Architecture Philosophy

Instead of complicated designs:

```text
Small Filter
Small Filter
Small Filter
Pool
Repeat
```

Very simple and uniform.

---

# VGG16 Architecture

The most famous version is **VGG16**.

The number 16 means:

```text
13 Convolution Layers
+
3 Fully Connected Layers
=
16 Learnable Layers
```

---

Architecture:

```text
Input (224×224×3)

Conv 3×3
Conv 3×3
MaxPool

Conv 3×3
Conv 3×3
MaxPool

Conv 3×3
Conv 3×3
Conv 3×3
MaxPool

Conv 3×3
Conv 3×3
Conv 3×3
MaxPool

Conv 3×3
Conv 3×3
Conv 3×3
MaxPool

FC
FC
FC

Softmax
```

---

# VGG19

Similar idea:

```text
16 Conv Layers
+
3 FC Layers
=
19 Layers
```

Hence:

```text
VGG16
VGG19
```

---

# Feature Learning Intuition

Imagine classifying a dog.

### Early Layers

Learn:

```text
Edges
Corners
Lines
```

---

### Middle Layers

Learn:

```text
Eyes
Ears
Fur Texture
```

---

### Deep Layers

Learn:

```text
Dog Face
Entire Dog
```

Hierarchy:

```text
Pixels
 ↓
Edges
 ↓
Textures
 ↓
Parts
 ↓
Objects
```

Same principle as AlexNet, but deeper.

---

# Why Was VGG Better Than AlexNet?

### 1. Deeper Network

AlexNet:

```text
8 Layers
```

VGG:

```text
16 or 19 Layers
```

More representational power.

---

### 2. Small Filters

AlexNet:

```text
11×11
5×5
3×3
```

VGG:

```text
3×3 only
```

Simpler design.

---

### 3. Better Accuracy

VGG significantly improved ImageNet performance compared to AlexNet.

---

# Parameter Explosion Problem

VGG had a major drawback.

VGG16:

```text
138 Million Parameters
```

AlexNet:

```text
60 Million Parameters
```

---

Most parameters came from:

```text
Fully Connected Layers
```

This caused:

* Huge memory usage
* Slow training
* Slow inference

---

# Why Did VGG Become Popular?

Despite being heavy, VGG was:

### Simple

Easy to understand.

### Transfer Learning Friendly

Many pretrained models became available.

People still use VGG16 features today.

---

# Comparison: AlexNet vs VGG

| Feature    | AlexNet         | VGG          |
| ---------- | --------------- | ------------ |
| Year       | 2012            | 2014         |
| Depth      | 8 layers        | 16/19 layers |
| Filters    | 11×11, 5×5, 3×3 | Only 3×3     |
| Parameters | ~60M            | ~138M        |
| Accuracy   | Good            | Better       |
| Simplicity | Moderate        | Very simple  |

---

# Limitation of VGG

Researchers noticed:

> If deeper networks are better, let's make them even deeper.

They tried:

```text
20 Layers
30 Layers
50 Layers
100 Layers
```

Surprisingly, performance started getting worse.

---

# Why?

### Vanishing Gradient

Gradients became very small.

### Optimization Difficulty

Deep networks became harder to train.

Example:

```text
20-layer network
```

might perform better than:

```text
56-layer network
```

which seems counterintuitive.

---

This problem led to:

# ResNet (2015)

The key idea:

```text
Skip Connections
```

which solved the degradation problem and enabled:

```text
50
101
152
```

layer networks.

# 30-Second Interview Answer

> VGGNet is a deep convolutional neural network introduced in 2014 by the Visual Geometry Group at Oxford. Its main contribution was showing that deeper networks with small 3×3 convolution filters outperform shallower networks with larger filters. The most popular versions are VGG16 and VGG19. Although VGG achieved excellent accuracy and became widely used for transfer learning, it suffered from a very large number of parameters, which later motivated more efficient architectures such as GoogLeNet and ResNet.
